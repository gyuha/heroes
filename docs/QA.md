# T-011 MVP 기능·성능 검증

검증일: 2026-10-23. 담당: QA·성능 엔지니어. 커밋·src 수정·의존성 설치 없음.
공유 main 작업 트리(다수 미커밋 변경)를 검사했다. 검사 중 다른 팀의 작업도 진행되므로 고정된 출시 커밋에 대한 인증이 아니다.

## 판정

- **MVP 한 판 플레이 가능 승인: 아니오(검증 미완료로 보류).** 실제 AI 대 AI 15분 전투 종료와 양 진영의 세션 흐름은 확인했다. 양 진영을 사람이 모든 명령으로 끝까지 플레이한 증거, 시각·애니메이션 검수와 스크린샷이 부족하다. 게임이 진행 불가하다는 뜻은 아니다. 재현한 진행 불가 문제는 없다.
- **D-008 성능 목표: 측정 불가.** Apple M5/32GB 환경이며 M1/Iris Xe 기준 장비가 없다. 브라우저 rAF가 약 1fps에 제한되고 스크린샷 캡처도 실패한다. CPU 스로틀링은 GPU 성능을 재현하지 않는다. CPU 틱 측정만으로 5,000명 60fps를 통과 처리하지 않는다.
- T-015 균형 진단은 별도 범위이며 이번 승률로 균형을 판정하지 않는다.

- 전체 판: 같은 Node 옵션으로 `src/app/headless.ts --games 1 --seed 11 --plan A --json /tmp/heroes-qa-run1.json`.
- 증거: `tools/qa/session-smoke.log`, `tools/qa/browser-results.json`, `tools/qa/browser-evidence.txt`, `tools/qa/tick-benchmark.jsonl`, `tools/qa/full-game-1.json`, `tools/qa/full-game-2.json`(생성된 항목만 유효).

## 미검증 체크리스트

- 양 진영 수동 완주, 실제 지면 우클릭 이동·적 우클릭 공격·드래그 정면/폭·돌격·전진의 전체 입력→화면 반영, 선택 없음 **화면 안내**, 빠른 연타/중복 입력 스트레스.
- 다리 병목의 실제 그림, 고저 가독성(D-012), 진영 마커 가독성, 걷기/달리기/공격/피격/사망 전환·취소·발 미끄러짐·기병 속도.
- 브라우저 탭 전환 후 복귀, 다양한 해상도/화면 비율에서의 배치·가림·입력 좌표, 모바일 실기기.
- 저장/불러오기와 오디오 재생·중복: 이번 실행 미검증. 구현 범위/출시 요구는 디렉터 확인 필요(T-010 대기).
- 15분 **실시간** 브라우저 메모리 soak, 반복 재시작 후 JS heap/GPU 리소스 회수. 900초를 빠르게 계산한 Node 실행으로 대체하지 않는다.
- 목표 기기 1080p GPU/FPS, 전투 전체 구간 최악 프레임, 4배속의 최악 교전 틱.

## 성능 측정

실제 전체 판 9,560명(Node24, seed11/A): 평균 3.41ms/틱, 최대 128ms. 시스템별 평균: soldiers 2.26ms, grid 0.71ms, squads 0.14ms, melee 0.14ms, vision 0.07ms, contacts 0.03ms, AI/ranged 각 0.02ms. 렌더 비용은 포함하지 않는다.

병력별 탐색 측정은 동일 맵·42부대·seed11/A에서 부대 병력을 비례 반올림했다. 총 240초/4,800틱 중 첫 200틱 제외, 4,600샘플. **다른 팀의 GC 프로파일링 및 QA 결정론 실행과 동시 실행되었다. 스케줄링·GC 영향을 포함하므로 확정 성능 기준이나 병력 간 엄밀 비교에 사용하지 않는다.** 편성 변경으로 AI·교전 밀도도 달라진다.

## 재현한 문제

### QA-001 — 패배 결과 사유가 승리자 관점으로 표시됨

- 심각도: **중간**. 담당 후보: **UI**. 진행은 가능하지만 결과 원인을 반대로 이해하게 한다.
- 환경: 위 Ego Chrome, 개발 서버, 황토/청람 모두.
- 재현: 황토 선택→전투 시작→공격군 붕괴 상태 유도(개발 fixture: 공격 부대 state=destroyed/n=0)→실제 승패 검사 틱 진행→결과 화면 확인. 청람에서 깃발 점령 패배도 같은 방식으로 확인 가능.
- 기대: 황토 붕괴 패배는 “아군이 붕괴했다”, 청람 점령 패배는 “상대가 깃발을 점령했다”처럼 플레이어 관점으로 표시.
- 실제: 황토 패배 제목 아래 **“상대 군이 붕괴했다”**. 청람 패배 아래 **“깃발을 60초 동안 점령했다”**. 황토 시간 패배 아래 **“제한 시간까지 깃발을 지켰다”**.
- 증거: `tools/qa/browser-results.json`의 team1/collapse, team0/flagCaptured, team1/timeHeld. 스크린샷은 도구 캡처 실패로 없음.
- 재검증 기준: 승/패 양쪽 × 세 사유의 제목·설명이 해당 진영 관점에 일치. 결과 설명 생성 함수의 표 기반 자동 테스트 권장.

### QA-002 — 기본 Node26에서 문서 헤드리스 명령 실행 실패

- 심각도: **낮음**(검증 도구 호환). 담당 후보: **B / 테크니컬 아키텍트**.
- 재현: Node v26.8.2에서 문서대로 `node --experimental-transform-types --no-warnings --import ./tools/map/register.mjs src/app/headless.ts --games 1` 실행.
- 기대: 러너 실행 또는 지원 Node 버전이 안내됨.
- 실제: `node: bad option: --experimental-transform-types`, 종료 코드 9.
- 증거: 이 명령의 실측 오류. 설치된 Node24.13.0 절대 경로로 실행하면 정상(우회 확인). 프로젝트 Node 버전 고정/지원 버전 안내 권장.
